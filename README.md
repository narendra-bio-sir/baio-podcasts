# BAIO Podcasts

Audio podcast episodes for the [BAIO Learning System](https://narendra-bio-sir.github.io/BAIO-Learning-System-By-Narendra-Sir/).

They live in this separate repository so the main site stays under GitHub Pages' 1 GB size limit.
Folder names match the main site's (for example `pu2-ch12-assets/podcast-english.mp3`), and the
main site links to them at `https://narendra-bio-sir.github.io/baio-podcasts/<same path>`.

Spoken episodes are stored as 48 kbps mono MP3.
